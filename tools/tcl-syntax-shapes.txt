# tcl-syntax-shapes.txt - the syntax of every SD TCL verb, one per line.
#
# "NAME = markdown" per line.  mktclsyntax.py computes the roster from newvoc
# and REFUSES to write the card if a verb has no line here, or if a line here
# names something that is not a verb.
#
# *italics* = you supply it.  `backticks` = typed as it stands.  {braces} =
# optional.  A vertical bar separates alternatives.
#
# ***THIS FILE IS THE SOURCE OF TRUTH, NOT THE PROGRAMS' START-DESCRIPTION
# BLOCKS.***  Sixty-three of the ninety-seven catalogued verbs carry one and
# they are NOT used as content, for two reasons: they are written in a
# different notation, and several are stale.  Measured examples - LIST.READU's
# omits the DETAIL keyword it accepts; CREATE.ACCOUNT's predates the USER /
# GROUP / OTHER forms and every tier and access keyword; MODIFY.ACCOUNT's shows
# only the ADD/DELETE form; WHO.AM.I's is a sentence about the program rather
# than a syntax line.  mktclsyntax.py reports where this file and a
# START-DESCRIPTION disagree, as a lead to follow, never as a correction to
# apply.
#
# These lines come from documents 19 to 31 of the User set and 01 to 03 of the
# Administrator set, where they were measured against a running system.

tool.bulk = **`tool.bulk`**  —  a bulk update of one data file of the account: choose the records (conditions, a saved list or every record), up to ten operations from a closed set, a dry run that writes nothing, apply under record locks after a box that asks the file's name typed, and undo of the last run
tool.catalog = **`tool.catalog`**  —  the programs of the account on one screen: compiled or not, current or stale, and where each is cataloged (private, local, global); compile it, catalog it privately or locally, and take a catalog entry out, each through its own verb after a box that shows the command
tool.config = **`tool.config`**  —  the configuration on one screen (administrator): every parameter of **`sd.conf`** with what SD is running with, what the file says, the default and when a change takes effect, the backup directory and the operating system part of the settings report; **`E`** changes one of 14 tuning parameters through **`set.config`** behind a box answered Run, and shows why and the line to add by hand for every other
tool.dict = **`tool.dict`** {*file*}  —  the dictionary of a file on one screen: its items by type with their heading, format, conversion and expression, described in words; make an item (the page writes the record itself, after a box, only if dict-edit is on), edit one in SED, delete or compile one through its verb, try one on a record; and the file's indices (make, build, delete, list)
tool.entries = **`tool.entries`**  —  the master files page (administrator): the VOC entries, the dictionary items and the programs (K) of every registered account read from the account's own files, with the edit gates it holds; filter by a part of an id (or a heading) or find it in every account; a pointer whose target lies outside the account is marked **`>`**; **`E`** and **`N`** edit or make a record, **`D`** deletes one and **`C`** compiles a program (through **`run.in`**), each in its own account; **`G`** changes every row shown and **`U`** puts the last change back
tool.files = **`tool.files`**  —  the files of the account on one screen: kind, records, modulus, size, indices, trigger; make, clear and delete a file, each through its own verb after a box that shows the command; analyze a file and list its indices and triggers by handing the terminal to the verb
tool.jobs = **`tool.jobs`**  —  the Scheduled jobs page (administrator): every account and the paragraphs and sentences it may run from the command line, changed through **`set.batch`** after a box answered Run; **`J`** shows the administrator's own scheduled jobs, made, changed, deleted and run now through **`set.job`**
tool.query = **`tool.query`** {*file*}  —  the query and report builder: choose a file, mark its columns (break and total), set conditions, sorts and options, read the list / sort / count / sum sentence they make, run it into a results box, and save the query in your file &queries& and load it again; every sentence is checked before it runs
tool.remote = **`tool.remote`**  —  everything that reaches SD from outside, on one screen (administrator): the two doors as the machine reports them (**`remote.api`**, with the terminal given to the verb for its restart question, and **`remote.ssh`**, each changed after a box and the word OPEN to turn one on), the routes of each user account, the SDNet servers (**`delete.server`**; **`set.server`** with the terminal given to the verb), who is connected, and this machine's TLS identity
tool.test = **`tool.test`**  —  the tests of the account on one screen: the test.* programs of its program files, run with run and judged by the last line N passed, M failed (pass, fail, no verdict; an abort is a fail); run one, all of those shown or the failed ones (after a box), read what a test printed, compile a test that has no object code through basic after a box that shows the command
tool.voc = **`tool.voc`**  —  the vocabulary of the account on one screen: every VOC entry with its type, what it points at, whether the pointer works and how it differs from the VOC SD ships; an entry is edited in the IDE (its voc-edit gate asked), and a keyword entry is never deleted
